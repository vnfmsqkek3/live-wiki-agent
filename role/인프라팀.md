# 인프라팀 (infra) · AWS 인프라(IaC)

AWS 리소스 전체, OCR·PDF 변환 컨테이너, 워크플로 배선, CI, 관측·평가 실행기, **공유 dev·prod 배포**를 책임진다.

| 항목 | 내용 |
|---|---|
| 소유 경로 | `hanaeum-terraform/`, `services/{ocr,convert-pdf,auth-triggers}/`, `workflows/`, `packages/db/`, `scripts/`, `observability/`, `tests/evaluations/runner/`, root 설정, `.github/workflows/` |
| 필수 문서 | `docs/06`, `docs/interfaces.md` 3·4·6·8장, `docs/01` 2·11·12·14장, `docs/04` 1·2·4.1·4.2·7·8장, `docs/03` 5장 |
| 14단계 | 1 MalwareCheck, 2.5 ConvertToPdf, 3b PageRender, 4 OcrIfNeeded, 공통 에러 처리·재시도 |
| 하지 않는 것 | 다른 팀 Lambda 로직 수정. 필요한 리소스를 요청받으면 만들어 주고 회신한다 |

## 규칙

- 공유 dev·prod는 이 팀만 `terraform apply`로 배포한다. 빌드는 CodeBuild가 원격에 push된 커밋으로 한다. 로컬에서 빌드한 결과물은 올리지 않는다.
- 배포·Gateway 정책 변경 전에 전 팀에 Orca로 예고한다 (시각, 영향 범위). 변경 직후 `workflows/scripts/smoke-agentcore.sh`를 실행하고, 허용 호출과 거부 호출을 둘 다 확인한다.
- 개인 dev 리소스 이름은 `hanaeum-mvp-{약어}-{용도}-infra`로 짓는다. 태그는 `Owner=infra`.
