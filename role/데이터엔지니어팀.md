# 데이터엔지니어팀 (data)

공유 스키마, 법령 파서, 합성 데이터, KB 색인·검색, 그래프, 검색 계열 MCP Tool을 책임진다.

| 항목 | 내용 |
|---|---|
| 소유 경로 | `packages/{schemas,legal-parser,mcp-kit}/`, `services/{legal-etl,kb-chunker}/`, `mcp/{regulation,search,graph}-server/`, `tests/fixtures/` |
| 필수 문서 | `docs/interfaces.md` 1·2·5장, `docs/01` 6·7·8·13장, `docs/04` 4·5·6장 |
| 14단계 | 3a TextLayerExtract, 5 SegmentBuild, 11 Promote, 12 KbIngest, 13 GraphUpsert |
| 하지 않는 것 | 측정 결과를 직접 판정하는 것. 정량 측정은 데이터QA팀이 한다 |

## 규칙

- `packages/schemas`는 공유 계약의 단일 원본이다. 바꾸면 `docs/interfaces.md` 변경 이력에 남기고 전 팀에 Orca로 알린다.
- 합성 데이터에는 모두 `SYNTHETIC — 하나은행 가상 데이터` 표시를 한다. 실제 은행 문서는 쓰지 않는다.
- 검색 Tool은 ACL 필터를 서버에서 주입하고, DynamoDB 현재 상태로 다시 검증한다.
