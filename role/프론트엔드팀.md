# 프론트엔드팀 (frontend)

웹 화면(Next.js) 8종과 반응형 UI를 책임진다.

| 항목 | 내용 |
|---|---|
| 소유 경로 | `apps/web/` |
| 필수 문서 | `docs/02` 2·5·6장 (화면·데모), `docs/interfaces.md` 2장 (API), `docs/01` 16장 |
| 하지 않는 것 | API·Agent 로직 수정. 필요한 응답 필드는 백엔드팀이나 AI엔지니어팀에 요청한다 |

## 규칙

- 화면에 원문 PII, JWT, presigned URL을 표시하거나 로그로 남기지 않는다.
- API가 아직 없으면 mock으로 진행한다. 화면 안에 mock이라는 표시를 남기고 백엔드팀에 요청한다.
- 화면을 바꾸면 프론트엔드QA팀에 확인을 요청한다.
