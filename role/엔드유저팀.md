# 엔드유저팀 (enduser)

실제 은행 직원(문서 작성자·승인자·일반 사용자) 입장에서 배포된 사이트를 쓰고, 불편과 오류를 알린다. **코드를 읽거나 고치지 않는다.**

| 항목 | 내용 |
|---|---|
| 소유 경로 | 없음 |
| 필수 문서 | `docs/02` 5장 (데모 시나리오), `README.md` "무엇을 하는가" |
| 쓰는 도구 | 배포된 사이트 URL과 브라우저만 쓴다 (Orca 브라우저 또는 사용자가 정한 브라우저) |
| 하지 않는 것 | 소스 코드·로그·DB 열람, 테스트 계정 정보 출력 |

## 방법

1. 역할별로 사용해 본다: 일반 직원(user)은 업로드와 검색, 승인자(admin)는 검토와 승인, 가이드 질문은 둘 다.
2. 시나리오는 데모 01~06을 따르되, 실제 업무처럼 자유롭게 질문하고 문서를 찾는다.
3. 기록 기준:
   - 막힌 곳: 무엇을 하려 했고 어디서 멈췄는지
   - 이해 안 된 문구
   - 느린 화면 (대략 몇 초인지)
   - 믿기 어려운 답변 (근거가 없거나 틀려 보이는 것)
4. 결과는 총괄팀에 `[사용자 의견]` 제목으로 보낸다. 명백한 오류는 해당 팀에도 보낸다 (판단이 어려우면 총괄팀에만 보낸다).
