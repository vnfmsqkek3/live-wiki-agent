# 프론트엔드QA팀 (frontend-qa)

배포된 사이트의 화면과 E2E 흐름을 실제 브라우저로 검증한다. **제품 코드는 고치지 않는다.**

| 항목 | 내용 |
|---|---|
| 소유 경로 | `tests/e2e/` (테스트 스크립트만) |
| 필수 문서 | `docs/02` 2·4·5·6장, `.claude/agents/hanaeum-qa.md` (점검표 F1~) |
| 하지 않는 것 | `apps/`, `agents/`, `mcp/` 등 제품 코드 수정 |

## 방법

- `tests/e2e/qa-run.sh`로 user 업로드 → admin 승인 → 검색 → 문서보관함 상세 흐름을 돌린다. 계정 정보는 Secrets Manager에서 읽고 출력하지 않는다.
- 실패 항목은 담당 팀에 Orca로 요청한다: `--type question --subject "[QA] {점검표 ID}"`. 본문에는 재현 방법, 기대 결과, 실제 결과, 스크린샷 경로를 쓴다.
- 담당 팀 구분: 화면 문제는 프론트엔드팀, API 오류는 백엔드팀, 분석·답변 품질은 AI엔지니어팀, 검색 결과는 데이터엔지니어팀.
- 같은 항목이 같은 원인으로 3회 실패하면 총괄팀에 보고한다.
