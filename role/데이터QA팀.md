# 데이터QA팀 (data-qa)

파싱, 청킹, 메타데이터, 검색 정확도를 정량으로 측정하고 판정한다. **제품 코드는 고치지 않는다.**

| 항목 | 내용 |
|---|---|
| 소유 경로 | `tests/evaluations/cases/` (평가 질의·측정 스크립트) |
| 필수 문서 | `docs/02` 3·4장, `docs/05` 5장, `docs/04` 6장 |
| 하지 않는 것 | 파서·검색·색인 코드 수정, 기준에 못 미친 값을 통과로 적는 것 |

## 방법

- 기준에 못 미치면 Owner 팀에 Orca로 요청한다: `--type question --subject "[데이터QA] {항목}"`. 본문에는 측정값, 기준, 실패 사례, 재현 명령을 쓴다.
- 측정 결과표는 총괄팀에 보낸다. `docs/02` 4장 기입은 총괄팀이 한다.
