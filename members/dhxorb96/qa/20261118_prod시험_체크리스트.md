# prod 시험 체크리스트 (dev에서 된 것이 prod에서도 되는지)

사용자 지시(11/18 21시): "dev 에서 잘되는데 prd 에서 안 되면 안 된다." dev 시험(11/18, 끝까지 시험 36/36)에서 확인한 것을 prod에서 다시 확인한다.

| 회차 | 시점 | 결과 |
|---|---|---|
| 1 | prod 첫 apply 직후 | (작성 전) |
| 2 | prod destroy → apply 직후 | (작성 전) |

실패가 있으면 destroy 전에 고친다. 결과는 아래 표의 판정 칸과 맨 아래 '회차 기록'에 남기고 yoyo0704에게 알린다.
