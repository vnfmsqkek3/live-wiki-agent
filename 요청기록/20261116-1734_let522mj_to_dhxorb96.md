## 요청 내용

1. **`packages/schemas` v0 리뷰** (리뷰어 dhxorb96). `interfaces.md` v0.1 변경: 메타데이터 `title`·`law_name`, ACL 키 `DEPT#{부서}`, 부칙·별표 ID
2. **Gateway 신원 전달** (`interfaces.md` 9장): MCP Tool은 `context.clientContext.custom.hanaeumActor` = `{ sub, groups, dept }`(JSON)만 신뢰하고 Tool 인자 속 사용자 정보는 무시한다 (`packages/mcp-kit`). M0 실험 결과 방식이 다르면 알려 달라
3. **승인 바인딩 해석**: Promote는 `approval.content_hash` = **quarantine `original.*` 바이트의 sha256**으로 보고 `APPROVED→USED` 조건부 전환한다. 승인 API가 다른 해시를 저장하면 맞춰야 함
4. **Documents 레코드 필드**: Promote가 읽는 필드 `doc_id, version, title, document_type, authority_status, conditional?, dept, acl_groups, law_id?, law_name?, revision_id?, effective_from?, effective_to?` (`services/legal-etl/src/store.ts` DocumentRecord). 검색 재검증은 `lifecycle, authority_status, conditional, freshness, acl_groups, content_hash`를 읽음 → Finalize에서 `content_hash`를 게시본 해시로 기록해 달라
5. **type-detection 허용 형식**: 합성 fixture가 `.txt`/`.md`라 데모 업로드용으로 허용하거나, PDF 변환본을 쓸지 정해 달라. 3a는 txt·md·pdf·png·jpg 지원, DOCX·HWPX는 미구현(명시적 실패)
6. **평가 데이터 사용**
   - 정상 5·위조 5·공격 5·충돌 5 지정 샘플: `tests/evaluations/cases/sets.json`
   - 근거 인용 20: `tests/evaluations/cases/citation.jsonl` (`expected_provision_ids`, `forbidden_*` 포함)
   - Trust Gate 대조 기준: `tests/fixtures/registry/registry*.json` (`content_hash`, `key_values`)
   - 노하우 인용 후보 추출 `extractCitations()` (`mcp/graph-server/src/citations.ts`) — Trust Gate 충돌 대조에 재사용 가능
7. **Change Impact 출력**: `trace_impact` → `{ changes[], impacted[{doc_id, relation, risk, recommended_freshness, evidence[]}] }`. 수정 초안·변경 영향 화면 입력으로 사용
