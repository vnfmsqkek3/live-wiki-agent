## 서비스별 설정

| 항목 | 웹 | API |
|---|---|---|
| 포트 | 3000 | 8080 |
| 헬스체크 | `GET /` | `GET /healthz` |
| CPU/메모리 (권고) | 0.25 vCPU / 512MB | 0.5 vCPU / 1GB |
| 빌드 인자 | `NEXT_PUBLIC_COGNITO_CLIENT_ID` (필수), `NEXT_PUBLIC_API_URL` 기본 `''` = 같은 도메인 | 없음 |
| 실행 env | `PORT`(기본) | `COGNITO_USER_POOL_ID`, `COGNITO_CLIENT_ID`, `TABLE_DOCUMENTS`·`TABLE_APPROVALS`·`TABLE_FEEDBACK`·`TABLE_AUDIT_EVENTS`·`TABLE_WORKFLOWS`, `BUCKET_QUARANTINE`, `PIPELINE_RUNTIME_ARN`, `AGENT_RUNTIME_ARN`(가이드 Agent), `GUARDRAIL_ID`·`GUARDRAIL_VERSION`(선택), `WEB_ORIGINS`=CloudFront 도메인, `AWS_REGION` |
| Task Role 권한 | 없음 | 위 DynamoDB 테이블 읽기·쓰기(Approvals 조건부 쓰기), quarantine presigned PUT·HeadObject, `bedrock-agentcore:InvokeAgentRuntime`(파이프라인·가이드), Guardrail ApplyGuardrail. **원본 객체 GetObject 불필요** |

## 주의

- CloudFront: `/v1/*`는 캐시 끔 + `Authorization` 헤더 전달. 웹 정적(`/_next/static/*`)만 캐시
- quarantine 버킷 CORS `web_origins`에 CloudFront 도메인 추가 (브라우저 presigned PUT)
- 배포 후 dhxorb96가 화면별 UI QA 진행
