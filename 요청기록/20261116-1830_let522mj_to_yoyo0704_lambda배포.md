## KB 데이터 소스 2개 (legal·knowledge) 공통

```hcl
vector_ingestion_configuration {
  chunking_configuration { chunking_strategy = "NONE" }          # 현재 그대로
  custom_transformation_configuration {
    intermediate_storage { s3_location { uri = "s3://hanaeum-mvp-s3-artifact-dev/kb-intermediate/" } }
    transformation {
      step_to_apply = "POST_CHUNKING"
      transformation_function { transformation_lambda_configuration { lambda_arn = <kb_chunker ARN> } }
    }
  }
}
```
- KB 서비스 Role에 kb_chunker `lambda:InvokeFunction`, intermediate 경로 Get·Put 필요
- 이벤트·출력 형식은 AWS 문서(kb-custom-transformation)와 일치 확인. 연결 후 1건 색인으로 실제 이벤트 검증하겠다
