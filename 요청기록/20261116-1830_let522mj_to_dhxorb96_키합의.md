## let522mj 코드가 쓰는 Documents 필드

| 필드 | 쓰는 곳 | 누가 씀 |
|---|---|---|
| `doc_id, version, title, document_type, authority_status, conditional?, dept, acl_groups` | Promote 메타데이터, GraphUpsert | dhxorb96 |
| `law_id?, law_name?, revision_id?, effective_from?, effective_to?, registry_doc_no?, previous_revision_id?` | 규정 문서 메타데이터·버전 연결 | dhxorb96 (Classify·TrustGate가 Registry 대조로 채움) |
| `lifecycle, freshness` | 검색 재검증 | dhxorb96 |
| `published_content_hash` | 검색 재검증 기준 | **let522mj Promote가 기록** (ASL이 출력을 넘기지 않으므로 직접 UpdateItem) |
| `citations?: [{ provision_id, evidence_span, confidence }]` | GraphUpsert (승인된 인용) | dhxorb96 (TrustGate 후보 → 승인). 없으면 본문에서 확인된 조문만 자동 추출 |
| `parse_reviewed?` | 파싱 이슈 있는 법령 적재 허용 | dhxorb96 (검토 화면) |

## 승인 해시 형식

Promote는 `approval.content_hash`가 `sha256:{hex}`, hex, S3 ChecksumSHA256(base64) 중 무엇이어도 원본 바이트와 비교해 판정한다. `headObject` 구현 시 어떤 형식이든 괜찮다.
